# Steam Workshop yayını
1. Orijinal ZIP dosyasını tamamen çıkart, oyun kapalı olsun.
2. Workshop/MoreLife klasörünü %USERPROFILE%\Zomboid\Workshop altına kopyala. Var olan workshop.txt içinde id= varsa koru.
3. Yerel test için Local/MoreLife klasörünü %USERPROFILE%\Zomboid\mods altına kopyala; aynı ID ile tek kopya kullan.
4. Test planını yeni kayıtta tamamla.
5. Steam'den oyunu aç > Workshop > Create and update items > MoreLife > Upload. İlk yayın Private. Steam yasal koşullarını oku ve kabul et.
6. Test başarılıysa Workshop öğe sayfasında görünürlüğü Public yap. Öğe bağlantısını ve ID'yi sakla.
Not: GitHub'daki kaynak henüz tam yayın arşivi değildir; görselleri içeren orijinal ZIP'i kullan.
